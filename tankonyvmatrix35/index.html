Miért kell a "Belső Dimenzió" Egyezése?

A mátrixszorzás nem elemenkénti szorzást jelent! A szorzás során úgynevezett **skaláris szorzatot (dot product)** képezünk egy teljes sora és egy teljes oszlop között.

1. "Mindenkinek kell legyen párja!"

Amikor az **A** mátrix i-edik sorát ráfektetjük a **B** mátrix j-edik oszlopára:

  • Az A sorának 1. elemét megszorozzuk a B oszlopának 1. elemével.
  • Az A sorának 2. elemét megszorozzuk a B oszlopának 2. elemével.
  • És így tovább...
Példa hibára: Ha az A sorában 3 elem van, de a B oszlopában csak 2, akkor a 3. elemnek nem lesz párja, amivel megszorozhatnánk! Ezért értelmezhetetlen a művelet.

Ha egy A(5 × 3) mátrixot megszorzunk egy B(3 × 2) mátrixszal, mekkora lesz a keletkező C mátrix mérete?

Algoritmus kódok: Python vs C++

Mindkét nyelvben 3 egymásba ágyazott `for` ciklussal valósítjuk meg a klasszikus mátrixszorzást ($O(N^3)$ időköltség).

# Mátrixszorzás Pythonban (3 egymásba ágyazott ciklussal)

def matrix_multiply(A, B):
    rows_A = len(A)
    cols_A = len(A[0])
    rows_B = len(B)
    cols_B = len(B[0])

    # 1. Ellenőrzés: A belső dimenzióknak meg KELl egyezniük!
    if cols_A != rows_B:
        raise ValueError("Hiba: Az A oszlopainak száma nem egyezik a B soraival!")

    # 2. Eredmény mátrix (C) inicializálása nullákkal (rows_A x cols_B)
    C = [[0 for _ in range(cols_B)] for _ in range(rows_A)]

    # 3. Három egymásba ágyazott ciklus (i: A sorai, j: B oszlopai, k: párosítás)
    for i in range(rows_A):
        for j in range(cols_B):
            for k in range(cols_A):  # k végigmegy az A során és B oszlopán párban!
                C[i][j] += A[i][k] * B[k][j]

    return C

// Mátrixszorzás C++ nyelven (std::vector használatával)
#include <iostream>
#include <vector>

using namespace std;

vector<vector<int>> multiplyMatrices(const vector<vector<int>>& A, const vector<vector<int>>& B) {
    int rows_A = A.size();
    int cols_A = A[0].size();
    int rows_B = B.size();
    int cols_B = B[0].size();

    if (cols_A != rows_B) {
        throw invalid_argument("A belső dimenziók nem egyeznek meg!");
    }

    // Eredmény mátrix lefoglalása 0 értékekkel
    vector<vector<int>> C(rows_A, vector<int>(cols_B, 0));

    // Ciklusok
    for (int i = 0; i < rows_A; ++i) {
        for (int j = 0; j < cols_B; ++j) {
            for (int k = 0; k < cols_A; ++k) {
                C[i][j] += A[i][k] * B[k][j];
            }
        }
    }

    return C;
}
