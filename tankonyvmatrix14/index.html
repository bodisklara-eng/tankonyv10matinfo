Golyó #2 (Értéke: 15)

Most a bot 2. indexű golyóját fogjuk meg.

Mivel a botot M = 3 golyónként törjük el:

  • Hányadik letört darabra (sorba) kerül? A golyó előtt 2 / 3 = 0 darab már teljesen megtelt sor van. Ez a sorindex ($r$).
  • A letört darab hányadik golyója lesz (oszlop)? Az aktuális darabon belül ez a 2 % 3 = 2. golyó. Ez az oszlopindex ($c$).

  • Hányadik letört darabra (sorba) kerül? A golyó előtt 5 / 3 = 1 darab már teljesen megtelt sor van. Ez a sorindex ($r$).
  • A letört darab hányadik golyója lesz (oszlop)? Az aktuális darabon belül ez a 5 % 3 = 2. golyó. Ez az oszlopindex ($c$).

Sorindex (r) = ⌊ 2 / 3 ⌋ = 0 (Sor száma)
Oszlopindex (c) = 2 mod 3 = 2 (Oszlop száma)
