class ForestMatrix:
    def __init__(self):
        self.grid = [
            ["Róka", "Üres", "Süni", "Üres", "Bagoly", "Üres"],
            ["Üres", "Őzike", "Üres", "Nyuszi", "Üres", "Medve"],
            ["Süni", "Üres", "Róka", "Üres", "Őzike", "Üres"],
            ["Üres", "Bagoly", "Üres", "Medve", "Üres", "Nyuszi"],
            ["Medve", "Üres", "Nyuszi", "Üres", "Róka", "Üres"],
            ["Üres", "Róka", "Üres", "Süni", "Üres", "Bagoly"]
        ]

    def touch_point(self, i, j):
        animal = self.grid[i][j]
        if animal != "Üres":
            return f"✨ M_forest[{i}][{j}] -> Átalakulás: {animal.upper()}! ✨"
        return f"M_forest[{i}][{j}] -> Csak varázsszikra."

🌲 Hogyan működik a Meseerdő?

  • Ceruza Mozgatás: Mozgasd az egeret a vásznon – a varázsceruza követi a kezed.
  • Pont Érintése: Ha a ceruzával egy fekete pont fölé mész, a jobb oldali M_forest mátrixban azonnal kivilágít a pontos sor- ($i$) és oszlopindex ($j$).
  • Kattintás / Átalakulás: Kattints a pontra, hogy felébreszd a pont alatt rejtőző meseállatot!
  • Python & C++ Kód: A jobb alsó ablakban élőben megtekintheted a mátrixkezelő kódot, és a Python Kód Futtatása gombbal ki is próbálhatod.
  • Újraindítás: A felső 🔄 gombbal az összes állatot visszaváltoztathatod ponttá.
