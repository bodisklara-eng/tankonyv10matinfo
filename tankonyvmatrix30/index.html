Mátrix Rendezés: Soronkénti Kódfuttatás & Debugger

Léptesd a kódot sornak megfelelően, és figyeld a változók és a 2D mátrix változását!

C++ Kód
// 1. Külső ciklus (menetek száma)
for (int i = 0; i < N * M - 1; i++) {
    // 2. Belső ciklus (szomszédok vizsgálata)
    for (int p = 0; p < N * M - i - 1; p++) {
        int r1 = p / M, c1 = p % M;
        int r2 = (p + 1) / M, c2 = (p + 1) % M;
        if (a[r1][c1] > a[r2][c2]) {
            swap(a[r1][c1], a[r2][c2]);
        }
    }
}
