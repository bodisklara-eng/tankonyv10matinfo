Egy kockának 6 lapja, 12 éle és 8 csúcsa van. Ahhoz, hogy síkba terítsük, a 12 élből pontosan 7 élt kell elvágni (ez egy feszítőfa a gráfelméletben).

  • Átfedés összehajtáskor: Két lap egymásra csukódik, így egy oldal nyitva marad.

  • 3x3-as tömb: Ha 4 lap találkozik egy sarokban, nem hajtogatható kockává.

Python Kódok (NumPy & SymPy 3D Transzformációk)

Így számíthatod ki Pythonban a kockahálók transzformációs mátrixait és szomszédsági grófjait.

1. 3D Forgatási Mátrixok Szorzása NumPy segítségével 

import numpy as np

def get_rotation_x(angle_deg):
    rad = np.radians(angle_deg)
    c, s = np.cos(rad), np.sin(rad)
    return np.array([
        [1,  0,  0,  0],
        [0,  c, -s,  0],
        [0,  s,  c,  0],
        [0,  0,  0,  1]
    ])

def get_translation(dx, dy, dz):
    return np.array([
        [1, 0, 0, dx],
        [0, 1, 0, dy],
        [0, 0, 1, dz],
        [0, 0, 0, 1]
    ])

# Transzformációk összekapcsolása Mátrixszorzással (@ operátor)
T = get_translation(0, 1, 0)
R = get_rotation_x(90)
M_final = T @ R  # Homogén transzformációs mátrix

point = np.array([0, 0, 0, 1])
transformed_point = M_final @ point
print("Transzformált csúcs 3D koordinátája:", transformed_point[:3])

2. Kockaháló Validálása Gráfelmélettel (NetworkX) 

import networkx as nx

def validate_cube_net_graph(adjacency_matrix):
    G = nx.from_numpy_array(adjacency_matrix)
    
    # 1. Pontosan 6 lapnak kell lennie
    if G.number_of_nodes() != 6:
        return False, "A lapok száma nem 6!"
        
    # 2. Összefüggő fának kell lennie (5 éllel)
    if not nx.is_tree(G):
        return False, "A háló nem alkot összefüggő fát!"
        
    return True, "Érvényes kockaháló fa-szerkezet!"
