C++ Matrice Beolvasás Szimulátor

A program csak a 3-jegyű számokat (100–999) fogadja el a while ciklus miatt.

Forráskód

unsigned int a[100][100], i, j, n;
cin >> n;
for(i = 1; i <= n; i++)
    for(j = 1; j <= n; j++) {
        cin >> a[i][j];
        while(a[i][j] < 100 || a[i][j] > 999)
            cin >> a[i][j];
    }
for(i = 1; i <= n; i++) { ... afișare ... }
