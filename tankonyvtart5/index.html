Lapozz 3D-ben, hasonlítsd össze a Min / Max / Hiba szinteket, és kérdezd a macskát!

MAXIMUM SZINT
3. Maximum / Haladó Szint (Dinamikus Vector)

3. oldal / 3
Kattints a cellákra a vizsgálathoz!
int n, m;
cin >> n >> m;
vector> a(n, vector(m, 5));
for (int i = 0; i < n; i++) {
    for (int j = 0; j < m; j++) {
        cout << a[i][j] << " ";
    }
    cout << endl;
}

📋 Kód Elemzés (Előnyök vs Hátrányok)

  • Előny (Max): Teljesen dinamikus méretezés futásidőben (n x m).
  • Előny: Biztonságos STL vektorok, automatikus memóriakezelés.
  • Hátrány: Kicsit bonyolultabb szintaxis a kezdő programozóknak.
