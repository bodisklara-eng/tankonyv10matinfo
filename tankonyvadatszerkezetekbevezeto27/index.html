2. fejezet • LED, PWM és időzítés

A villogástól a fényerőszabályzásig

A digitális kimenet kétállapotú jelként képzelhető el: LOW vagy HIGH. PWM-nél gyorsan váltogatjuk a jelet, és a kitöltési tényező határozza meg az átlagos teljesítményt.

🔍 MIT KELL MEGFIGYELNIE? 25% kitöltésnél a jel az idő nagyjából negyedében HIGH. A gyors váltás miatt a LED folyamatosabbnak látszó fényt ad.
C++ / Arduino
const int LED = 9;

void setup() {
  pinMode(LED, OUTPUT);
}

void loop() {
  analogWrite(LED, 64);   // kb. 25%
  delay(1000);

  analogWrite(LED, 255);  // 100%
  delay(1000);
}
MicroPython / Python
from machine import Pin, PWM
from time import sleep

led = PWM(Pin(15))
led.freq(1000)

while True:
    led.duty_u16(16384)  # kb. 25%
    sleep(1)

    led.duty_u16(65535)  # 100%
    sleep(1)
📌 MIT KELL MEGJEGYEZNIE? A PWM nem egyszerűen „kevesebb feszültséget” jelent: gyors impulzussorozattal szabályozzuk az energiaátadást. A pontos működés az adott mikrokontroller és terhelés tulajdonságaitól függ.

Piezo, tranzisztor és terhelés

A mikrokontroller kimenete nem minden terhelés közvetlen meghajtására alkalmas. Nagyobb áramigényű terhelésnél gyakran tranzisztoros vagy MOSFET-es kapcsoló fokozatot alkalmazunk.

🔍 MIT KELL MEGFIGYELNIE? A piezo hangkeltőnél a vezérlőjel frekvenciája határozza meg a hangmagasságot. A LED fényerejénél inkább a PWM kitöltési tényezője a döntő.
📌 MIT KELL MEGJEGYEZNIE? Motor, relé vagy más induktív terhelés esetén megfelelő meghajtás és védelem szükséges. Mindig az adott alkatrész adatlapja alapján méretezzen.
C++ / Arduino – hang
const int BUZZ = 8;

void setup() {}

void loop() {
  tone(BUZZ, 880); // A5 körüli hang
  delay(250);
  noTone(BUZZ);
  delay(250);
}
MicroPython – hang
from machine import Pin, PWM
from time import sleep

buzzer = PWM(Pin(15))
buzzer.freq(880)

while True:
    buzzer.duty_u16(20000)
    sleep(.25)
    buzzer.duty_u16(0)
    sleep(.25)
