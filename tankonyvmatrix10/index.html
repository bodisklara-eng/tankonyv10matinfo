Mi az a Ritka Mátrix (Sparse Matrix)?
Amikor a 10x10-es Puzzle rácsban vagy a Meseerdő pályáján játszol, a mezők többsége üres (0 értékű). Az olyan mátrixot, amelyben a cellák túlnyomó része nulla, ritka mátrixnak nevezzük.

1.1 Hagyományos Tárolás vs. Memóriapazarlás

Egy $1000 \times 1000$-es játéktér 1 000 000 elemet tartalmaz. Ha csak 5 elemet raksz le a rácsra, a többi 999 995 mező feleslegesen foglalja a RAM memóriát!

❓ Interaktív Kérdés: Mennyi memóriát spórolunk?

Kérdés: Ha egy 10x10-es rácson csak 4 puzzle elem van lerakva, hány százaléka a mátrixnak üres (0)?

Válasz: A 100 mezőből 96 mező üres, vagyis a mátrix 96%-a felesleges adat. Ezért van szükségünk intelligens tárolásra!

1.2 A CSR (Compressed Sparse Row) Megoldás

A CSR módszer ahelyett, hogy az egész rácsot elmentené, mindössze 3 egyszerű tömbbel jegyzi meg a lerakott elemeket:

  • data (értékek): [5, 8, 3, 6] (csak a lerakott elemek)
  • indices (oszlopok): [0, 2, 1, 3] (melyik oszlopban vannak)
  • indptr (sor-mutatók): [0, 1, 2, 4, 4] (hol kezdődnek a sorok)

Programozás és Gyakorlás

2.1 Python SciPy CSR Implementáció

Így alakíthatod át a játékrácsot memóriatakarékos CSR mátrixszá Pythonban:

import numpy as np from scipy.sparse import csr_matrix # 1. Játékrács létrehozása (Sűrű mátrix) jatekracs = np.array([ [5, 0, 0, 0], [0, 0, 8, 0], [0, 3, 0, 6], [0, 0, 0, 0] ]) # 2. Átalakítás CSR ritka mátrixszá (Memória spórolás!) ritka_racs = csr_matrix(jatekracs) print("A eltárolt elemek:", ritka_racs.data) # [5 8 3 6] print("Oszlop pozíciók:", ritka_racs.indices) # [0 2 1 3] # 3. Gyors transzformáció vektorral v = np.array([1, 2, 3, 4]) eredmeny = ritka_racs.dot(v) print("Transzformált értékek:", eredmeny)
