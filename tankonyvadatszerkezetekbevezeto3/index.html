Vector-of-Vectors Algoritmus Szimulátor

Párhuzamos C++ és Python végrehajtás lépésről lépésre

Sebesség:
Lépés: 1 / 6
C++ (std::vector<std::vector<Student>>)
C++17 
#include <iostream>
#include <vector>
#include <string>

struct Student { std::string name; int day; };

int main() {
    // 1. 12 hónap inicializálása üres vektorokkal
    std::vector<std::vector<Student>> birthdayCalendar(12);

    // 2. Diákok besorolása a hónap index szerint (0-11)
    birthdayCalendar[0].push_back({"Anna", 12});
    birthdayCalendar[0].push_back({"Péter", 24});
    
    // 3. Iteráció a vector-of-vectors struktúrán
    for (size_t m = 0; m < birthdayCalendar.size(); ++m) {
        for (const auto& student : birthdayCalendar[m]) {
            std::cout << "Hónap " << m+1 << ": " << student.name << "\n";
        }
    }
    return 0;
}
