Mátrixok Rendezése és Indextranszformációja

Középiskolai tankönyvi fejezet • Elmélet, Szimuláció és Tesztfeladatok

1. Bevezetés és Alapfogalmak

Az informatikában és a programozásban a kétdimenziós tömbök (mátrixok) rendezése az egyik legalapvetőbb adatszerkezeti művelet. A mátrix elemeinek sorfolytonos rendezése során célunk, hogy a mátrix elemei balról jobbra, fentről lefelé növekvő (vagy csökkenő) sorrendbe kerüljenek.

Egy N × M méretű mátrix esetén a teljes elemszám K = N × M. A rendezés megvalósítására két fő módszertani megközelítés létezik:

1. Módszer: Vektorba másolásos rendezés (Közvetett rendezés)
A 2D mátrix elemeit egy 1D tömbbe (vektorba) soroljuk át, ott elvégezzük a hagyományos rendezést (pl. Buborék-, Kijelöléses vagy Beszúrásos rendezés), majd a rendezett elemeket visszamásoljuk a mátrixba.
2. Módszer: Helyben (Közvetlen) történő rendezés
Nem használunk segédvektort. A mátrix elemeit közvetlenül a 2D struktúrában hasonlítjuk össze és cseréljük ki, az indexek lineáris leképezésével.

2. Az Indextranszformáció Matematikai Háttere

A rendezés legkritikusabb lépése az 1D lineáris index (k) és a 2D mátrix koordinátái (r: sor, c: oszlop) közötti transzformáció. Ez a matematikai kapcsolat biztosítja, hogy a vektorba rendezett elemek pontosan a megfelelő sorfolytonos pozícióra kerüljenek vissza.

Transzformációs Képletek (M oszlop esetén):

Sor indexe: r = ⌊k / M⌋          Oszlop indexe: c = k mod M

Ahol:

  • k: az 1D vektor indexe (0 ≤ k < N × M)
  • M: a mátrix oszlopainak száma
  • ⌊k / M⌋: egészosztás (azt adja meg, hány egész sor telt be)
  • k mod M: az oszlopindex (a soron belüli maradék pozíció)

Mintapélda Levezetése (2 × 3-as mátrix, M = 3)

Tegyük fel, hogy az eredeti mátrixunk A = [[42, 15, 8], [23, 4, 19]]. A vektorba másolás és rendezés után a vektor állapota: vec = [4, 8, 15, 19, 23, 42].

Vektor index (k) Érték (vec[k]) Sor kiszámítása (r = ⌊k / 3⌋) Oszlop kiszámítása (c = k mod 3) Mátrix pozíció (A[r][c])
0 4 0 / 3 = 0 0 mod 3 = 0 A[0][0]
1 8 1 / 3 = 0 1 mod 3 = 1 A[0][1]
2 15 2 / 3 = 0 2 mod 3 = 2 A[0][2]
3 19 3 / 3 = 1 3 mod 3 = 0 A[1][0]
4 23 4 / 3 = 1 4 mod 3 = 1 A[1][1]
5 42 5 / 3 = 1 5 mod 3 = 2 A[1][2]

📌 MEGJEGYZENDŐ KÓDTÁR ÉS BÖLCSESSÉGEK

  • Oszlopszám szerepe: A képletekben mindig a **mátrix oszlopainak száma (M)** szerepel az osztóban, SOHA nem a sorok száma!
  • Inverz transzformáció: Ha a 2D indexből (r, c) szeretnénk megkapni az 1D indexet (k): k = r × M + c.
  • Memória hatékonyság: A közvetlen helyben rendezés memóriaigénye O(1), míg a vektoros módszeré O(N × M) plusz tárhelyet igényel.

3. Algoritmusok Implementációja (C++ és Python)

// C++: Visszamásolás Vektoros Rendezés Után int k = 0; for (int r = 0; r < N; r++) { for (int c = 0; c < M; c++) { A[r][c] = vec[k++]; // Ezzel egyenértékű: vec[r * M + c] } } // C++: Közvetlen Mátrix Buborékrendezés int total = N * M; for (int i = 0; i < total - 1; i++) { for (int p = 0; p < total - i - 1; p++) { int r1 = p / M, c1 = p % M; int r2 = (p + 1) / M, c2 = (p + 1) % M; if (A[r1][c1] > A[r2][c2]) swap(A[r1][c1], A[r2][c2]); } }

4. Ellenőrző Tesztkérdések és Feladatok

1. Egy 4 sorból és 5 oszlopból álló mátrix esetén hova kerül az 1D vektor 13-as indexű eleme a visszamásoláskor?
A) A[2][3] (3. sor, 4. oszlop)
B) A[3][2] (4. sor, 3. oszlop)
C) A[2][2] (3. sor, 3. oszlop)
D) A[1][3] (2. sor, 4. oszlop)
2. Mi az inverz transzformáció képlete, amellyel az A[r][c] elem 1D vektoros indexét megkapjuk?
A) k = c * N + r
B) k = r * M + c
C) k = (r + c) * M
D) k = r * N + c
3. Milyen tárhely-összetettségű (Space Complexity) a közvetlen mátrixrendezés?
A) O(N * M)
B) O(N + M)
C) O(1)
D) O(log(N*M))
Helyes válaszok és magyarázatok:
1. A) r = ⌊13 / 5⌋ = 2, c = 13 mod 5 = 3. Tehát a 2. indexű sor 3. indexű oszlopa.
2. B) A sorszámot megszorozzuk az oszlopok számával (M), majd hozzáadjuk az oszlopindexet (c).
3. C) Mivel nem hozunk létre plusz tömböt, a memóriaszükséglet konstans: O(1).
