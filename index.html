Elméleti Háttér

Fedési Problémák (Overlap) & Réteg-Mátrixok (Layering)

1. Egyszerű Cellafelülírás (Adatvesztés)

Ha egy 2D-s tömbben egy cellában csak **egyetlen értéket** tárolunk, felülfedés esetén az alul lévő alakzat adata véglegesen megsemmisül!

M[4][5] = SHAPE_TRIANGLE; // Háromszög
M[4][5] = SHAPE_SQUARE; // HIBA: A háromszög elveszett!

2. Réteg-Mátrix / Stack Cellák (Megoldás)

Minden cellában egy **Stack-et (Vektoros Listát)** tartunk fenn (`M[row][col][layer]`), így a Z-sorrend és az áttetszőség is megmarad!

M[4][5].push(SHAPE_TRIANGLE); // Réteg 0
M[4][5].push(SHAPE_SQUARE); // Réteg 1 (Tetején)

SZEMLÉLTETÉS & ÖSSZEHASONLÍTÁS

Adatszerkezeti Opciók Részletes Példái

Nézzük meg az 5. fejezet kvízkérdésének 3 opcióját működés és kód szempontjából!

OPTION A 1D Tömb (Float Array)

a) Egydimenziós float tömb (`float array[N]`)

Egy egydimenziós tömbben a kétdimenziós rácsot indexszámítással sorfolytonosan tárolhatjuk (index = row * cols + col), vagy lefedettségi tényezőket / átlátszósági értékeket (0.0–tól 1.0–ig) írhatunk bele.

// C++ Példa:
float grid1D[144]; // 12×12 rács 1D-ben
// Elérés: row=3, col=4
grid1D[3 * 12 + 4] = 0.85f; // 85% lefedettség
// Python Példa:
import numpy as np
grid_1d = np.zeros(144, dtype=float)
grid_1d[3 * 12 + 4] = 0.85
Korlát: Nem képes több egymásra helyezett alakzat Z-sorrendjének és egyedi azonosítóinak tárolására.
OPTION B (HELYES) Dinamikus Stack / Vektorok Vektora

b) Dinamikus lista / Stack (Vektorok vektora cellánként)

A rács minden egyes cellája önmagában egy dinamikusan növekvő listát / vermet tárol. Ha új alakzat takarja be az adott cellát, az felkerül a lista tetejére. Így a teljes rétegrend és átfedés megmarad.

// C++ Példa (std::vector 3D):
std::vector<Shape> grid[12][12];
grid[3][4].push_back(triangle); // 0. Réteg
grid[3][4].push_back(square); // 1. Réteg (Felül)
// Python Példa:
grid_stack = [[[] for _ in range(12)] for _ in range(12)]
grid_stack[3][4].append({"type": "triangle"})
grid_stack[3][4].append({"type": "square"})
Előny: Veszteségmentes! Rekonstruálható az eredeti kirakó teljes rétegrendje.
OPTION C Bool Matrix

c) Logikai (bool) mátrix (`bool M[12][12]`)

Egyszerű bináris mátrix: egy adott celláról csak annyit mond meg, hogy **foglalt-e (true)** vagy **üres (false)**.

// C++ Példa:
bool isOccupied[12][12] = {false};
isOccupied[3][4] = true; // Van itt valami
// Python Példa:
import numpy as np
is_occupied = np.zeros((12, 12), dtype=bool)
is_occupied[3, 4] = True
Korlát: Csak az érzékelhető, hogy üres-e a pixel, az alakzat típusa, színe és rétege elveszik.

10. Osztály 
#include <iostream>
#include <vector>
#include <string>

struct Shape {
    int id;
    std::string type; // "triangle_lg", "square"
    double rotation;  // tetszőleges fok
    std::string colorHex;
};

using LayerMatrix = std::vector<std::vector<std::vector<Shape>>>;

int main() {
    LayerMatrix grid(12, std::vector<std::vector<Shape>>(12));

    Shape triangle{1, "triangle_lg", 315.0, "#e74c3c"};
    grid[4][5].push_back(triangle);

    Shape square{2, "square", 0.0, "#f97316"};
    grid[4][5].push_back(square);

    std::cout << "Cella [4][5] rétegei: " << grid[4][5].size() << std::endl;
    return 0;
}
# 12x12-es Mátrix inicializálása dinamikus listákkal
grid_matrix = [[[] for _ in range(12)] for _ in range(12)]

shape_1 = {"id": 1, "type": "triangle_lg", "rotation": 315.0, "color": "#e74c3c"}
shape_2 = {"id": 2, "type": "square", "rotation": 0.0, "color": "#f97316"}

grid_matrix[4][5].append(shape_1) # Réteg 0
grid_matrix[4][5].append(shape_2) # Réteg 1 (Fedés)

def get_top_shape(row, col):
    cell = grid_matrix[row][col]
    return cell[-1] if cell else None

print(f"Legfelső alakzat [4][5]: {get_top_shape(4, 5)}")
