Két mátrix csak akkor szorozható össze, ha az A mátrix oszlopainak száma (K) megegyezik a B mátrix sorainak számával (K). Ennek oka, hogy a szorzás során az A sorának minden elemét párba kell állítani a B oszlopának megfelelő elemével.

4. Programkód Implementációk

Nézd meg, hogyan valósítható meg a mátrixszorzás Python-ban és C++-ban!

# Mátrixszorzás megvalósítása Python nyelven (Három egymásba ágyazott ciklussal)

def matrix_multiply(A, B):
    M = len(A)        # A sorainak száma
    K = len(A[0])     # A oszlopainak (és B sorainak) száma
    N = len(B[0])     # B oszlopainak száma
    
    # Eredmény mátrix inicializálása nullákkal (M x N dimenzió)
    C = [[0 for _ in range(N)] for _ in range(M)]
    
    # 1. Külső ciklus (i): A sorain megy végig
    for i in range(M):
        # 2. Középső ciklus (j): B oszlopain megy végig
        for j in range(N):
            # 3. Belső ciklus (k): Összegzés végrehajtása
            for k in range(K):
                C[i][j] += A[i][k] * B[k][j]
                
    return C

# Példa használat:
matrix_A = [[1, 2, 3], [4, 5, 6]]
matrix_B = [[7, 8], [9, 1], [2, 3]]
eredmeny = matrix_multiply(matrix_A, matrix_B)
print("Eredmény:", eredmeny)
// Mátrixszorzás megvalósítása C++ nyelven (std::vector használatával)
#include <iostream>
#include <vector>

using namespace std;

vector<vector<int>> matrixMultiply(const vector<vector<int>>& A, const vector<vector<int>>& B) {
    int M = A.size();
    int K = A[0].size();
    int N = B[0].size();

    // M x N dimenziójú eredménymátrix létrehozása 0 értékekkel
    vector<vector<int>> C(M, vector<int>(N, 0));

    // Három egymásba ágyazott ciklus (i, j, k)
    for (int i = 0; i < M; ++i) {
        for (int j = 0; j < N; ++j) {
            for (int k = 0; k < K; ++k) {
                C[i][j] += A[i][k] * B[k][j];
            }
        }
    }
    return C;
}

int main() {
    vector<vector<int>> A = {{1, 2, 3}, {4, 5, 6}};
    vector<vector<int>> B = {{7, 8}, {9, 1}, {2, 3}};
    
    auto C = matrixMultiply(A, B);
    return 0;
}

Páronkénti Szorzás és Összegzés

Az C[i][j] elem kiszámításához az A mátrix i-edik sorát és a B mátrix j-edik oszlopát használjuk. Minden egymásnak megfelelő elemet megszorzunk, majd a kapott szorzatokat összeadjuk.

Műveletigény & Lépésszám

A klasszikus mátrixszorzás műveletigénye: M × K × N szorzási és összeadási lépés. Ha mindhárom dimenzió N nagyságú, akkor a szükséges lépések száma N³ (köbös növekedés).
