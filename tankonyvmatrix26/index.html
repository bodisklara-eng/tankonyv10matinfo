4.2. Mátrixok Sorfolytonos Visszapakkolása és Indextranszformációja

Bevezetés: A számítástechnikában a kétdimenziós mátrixok memóriabeli reprezentációja leggyakrabban egydimenziós, folytonos memóriaterületen (vektorban) történik. Amikor egy kétdimenziós tömb elemeit rendezni kívánjuk, az egyik legegyszerűbb és leghatékonyabb eljárás a mátrix "kisimítása" 1D vektorrá, a rendezés elvégzése, majd az adatok visszamásolása az eredeti 2D szerkezetbe.

1. A "Bottörés" Vizuális és Fizikai Analógiája

Képzeljünk el egy egyenes pálcát (botot), amelyre egymás után fel vannak fűzve a rendezett értékeket hordozó golyók. Legyen ez a bot egy K elemű egydimenziós tömb (vektor). A mátrixba történő visszapakkolás nem más, mint ennek a botnak a szabályos darabolása és egymás alá helyezése.

Eredeti Bot (1D Vektor, K = 6):
[ (0) 4 ] === [ (1) 8 ] === [ (2) 15 ] === [ (3) 19 ] === [ (4) 23 ] === [ (5) 42 ]
                                           ✂ (Törés M = 3 elemnél)

Egymás alá pakolt törött darabok (2D Mátrix, 2x3):
0. sor: [ 4 ][ 8 ][ 15 ]
1. sor: [ 19 ][ 23 ][ 42 ]
4.1. ábra: A bot eltörése M = 3 oszlopszélességű darabokra és egymás alá illesztése.

A törés helyét az oszlopok száma (M) határozza meg. Minden alkalommal, amikor a botra felfűzött golyók száma eléri az M értéket, a botot eltörjük, és egy új sort kezdünk alatta.

2. A Matematikai Leképezés Bizonyítása

Tételezzük fel, hogy a K hosszúságú vektor i-edik elemét (i ∈ {0, 1, ..., K−1}) szeretnénk elhelyezni egy N sorból és M oszlopból álló mátrix A[r][c] pozíciójára.

Tétel: A sorfolytonosan tárolt vektor i-edik elemének mátrixbeli sorindexe (r) és oszlopindexe (c) egyértelműen meghatározható az alábbi zárt képletekkel:
Sorindex: r = ⌊
iM
⌋          Oszlopindex: c = i mod M

Bizonyítás: A sorfolytonos elrendezés miatt az első r darab megtelt sor pontosan r × M elemet tartalmaz. Az r-edik sorba kerülő elemek indexei a vektorban a következő zárt intervallumba esnek:

i ∈ [r · M,  (r + 1) · M − 1]

Osztva az egyenlőtlenséget M-mel:

r ≤
iM
< r + 1

A padló-függvény (egészosztás) definíciójából adódóan az r értékekre pontosan r = ⌊i / M⌋ adódik. Az oszlopindex a maradék: c = i mod M. ∎

3. Algoritmus és Programozási Implementációk

A levezetett matematikai összefüggés közvetlenül átültethető C++ és Python programozási nyelvekre. Az alábbi kódok bemutatják a teljes folyamatot.

3.1. C++ Implementáció

#include <iostream>
#include <vector>
#include <algorithm>

void rendezEsVisszapakkol(int A[2][3], int N, int M) {
    int K = N * M;
    std::vector<int> vec;

    // 1. Kisimítás (2D -> 1D)
    for (int r = 0; r < N; ++r) {
        for (int c = 0; c < M; ++c) {
            vec.push_back(A[r][c]);
        }
    }

    // 2. Rendezés
    std::sort(vec.begin(), vec.end());

    // 3. Visszapakkolás az i / M és i % M képletek alapján
    for (int i = 0; i < K; ++i) {
        int r = i / M; // Egészosztás: megadja a sorindexet
        int c = i % M; // Maradékképzés: megadja az oszlopindexet
        A[r][c] = vec[i];
    }
}

3.2. Python Implementáció

def rendez_es_visszapakkol(A, N, M):
    # 1. Kisimítás (2D -> 1D)
    vec = [elem for row in A for elem in row]
    
    # 2. Rendezés
    vec.sort()
    
    # 3. Visszapakkolás az i // M és i % M képletek alapján
    for i in range(len(vec)):
        r = i // M  # Egészosztás (Sor)
        c = i % M   # Maradékképzés (Oszlop)
        A[r][c] = vec[i]
        
    return A

4. Összefoglaló Ellenőrző Kérdések

  2. Miért az oszlopszámmal (M) végzünk egészosztást a sorindex kiszámításához, és miért nem a sorszámmal (N)?

Válasz az 1. kérdésre: r = ⌊13 / 5⌋ = 2 (3. sor), c = 13 mod 5 = 3 (4. oszlop). A keresett pozíció: A[2][3].
