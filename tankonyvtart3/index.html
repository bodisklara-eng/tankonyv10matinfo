3×3 Mátrix Helyes Indexeléssel

A C++ nyelvben a tömbök indexelése 0-tól kezdődik és a méret - 1-ig tart. Egy 3×3-as mátrix esetén az érvényes indexek: 0, 1, 2. 

#include <iostream>
using namespace std;

int main() {
    int a[3][3] = {
        {5, 5, 5},
        {5, 5, 5},
        {5, 5, 5}
    };

    for (int i = 0; i < 3; i++) { // 0-tól indul!
        for (int j = 0; j < 3; j++) {
            cout << a[i][j] << " ";
        }
        cout << endl;
    }
    return 0;
}

Gyakori Hiba (1-től indexelés)

Mi történik, ha 1-től próbálsz indexelni?

Sok kezdő programozó megszokásból i = 1 és i <= 3 feltételt ír. Ennek súlyos következményei vannak:

  • Meghatározatlan viselkedés (Undefined Behavior): Az a[3][3] elemre hivatkozva a memória egy nem engedélyezett területét érjük el.
  • Kihagyott adatok: A 0 indexű sor/oszlop benne sem lesz a ciklusban, míg a túlindexelt elem szemét értéket ad vissza vagy összeomlasztja a programot.

Hibás Ciklus Példa

// ROSSZ CIKLUS:
for (int i = 1; i <= 3; i++) {
    for (int j = 1; j <= 3; j++) {
        // Túlindexelés veszélye!
        cout << a[i][j]; 
    }
}
Ha 4×4-es Tömbhöz Ragaszkodsz

Hogyan kezeljük a 4×4-es mátrixokat?

Ha a feladat vagy az elképzelés 4×4 méretű tömböt követel meg, akkor a deklarációt és a ciklusokat is pontosan ehhez kell igazítani, hogy ne maradjon üresen vagy hibásan elem.

1

Deklaráld helyesen: int a[4][4];

2

Írd a ciklusokat i = 0; i < 4; i++ formában.

3

Töltsd fel mind a 16 elemet, és figyelj arra, hogy az indexek 0-tól 3-ig terjedjenek!

4×4 C++ Példa 
int a[4][4]; // 16 elem

for (int i = 0; i < 4; i++) {
    for (int j = 0; j < 4; j++) {
        a[i][j] = (i + 1) * (j + 1);
    }
}
Haladó / Dinamikus Mátrix

Dinamikus Mátrixfeltöltés

Mi van akkor, ha futási időben szeretnéd megadni a mátrix méretét (N × M)? Ehhez pointereket (int**) vagy std::vector-t használunk!

Dinamikus mátrix memóriafoglalás indítása... 1. Felhasználói bemenet beolvasása: N = 3, M = 3 2. Vektor deklarálás: vector> matrix(3, vector(3, 5)); 3. Memória lefoglalva a heapen biztonságosan. 4. Elemek sikeresen kiíratva 0-s indexeléssel: 5 5 5 5 5 5 5 5 5 Sikeres futás!

Miért hasznos a std::vector?

C++-ban a statikus tömbök méretét fordítási időben kell tudni. A vector<vector<int>> automatikusan kezeli a memóriát, így elkerülhető a memóriaszivárgás (memory leak) és a manual delete[] hívások elfelejtése.

Részletes Elmélet és Különbségek

Miért 0-tól indexel a C++?

A C és C++ nyelvekben a tömb neve lényegében egy memóriacím pointer az első elemre. Az index azt határozza meg, hogy hány bájttal vagy memóriarekeszel tolódjunk el attól a címtől. A a[0] pontosan 0 eltolást jelent (az első elem).

Statikus vs. Dinamikus Mátrix: Mikor melyiket használjuk?

Statikus Mátrix
  • Mérete fix (pl. int a[3][3]).
  • Gyors, a veremben (stack) tárolódik.
  • Akkor használd: Ha pontosan tudod előre, hogy mekkora rácsra van szükséged (pl. sakktábla 8×8, Pascal-háromszög).
Dinamikus Mátrix
  • Futásidőben kap méretet (pl. felhasználótól beolvasva).
  • A halmon (heap) tárolódik std::vector-ral.
  • Akkor használd: Ha a méret a felhasználói bemenettől függ, vagy dinamikusan változhat.

Összegző Tanulság

Mindig figyelj a ciklushatárokra! Ha N méretű a tömb, a ciklus feltétele mindig i < N legyen, soha ne i <= N, különben túlindexeled a memóriát.
