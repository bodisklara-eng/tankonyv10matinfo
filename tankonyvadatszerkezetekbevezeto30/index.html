2. Gondolatmenet: A Fedés (Overlap) és Z-Index Problémája

Ha két alakzat átfedi egymást a rácson, az egyszerű 2D érték-mátrix `M[r][c]` felülírja a korábbi értéket. Az alul fekvő alakzat adatai véglegesen megsemmisülnek. Ennek kiküszöbölésére cellánkénti **Stack (dinamikus réteg-lista)** adatszerkezetet használunk.

Réteg-Stack Implementáció (C++ & Python)

// C++ 3D Vektor Réteg-Stack 
#include <vector>

struct Shape { int id; std::string type; };

// 12x12-es rács, minden cellában Stack
std::vector<Shape> grid[12][12];

// Rétegek hozzáadása (0. alsó, 1. felső)
grid[3][4].push_back({1, "triangle"});
grid[3][4].push_back({2, "square"});
# Python Dinamikus Stack 
# 12x12 Mátrix listákkal
grid_stack = [[[] for _ in range(12)] 
              for _ in range(12)]

# Rétegek beszúrása
grid_stack[3][4].append({"id": 1, "t": "tri"})
grid_stack[3][4].append({"id": 2, "t": "sq"})

top = grid_stack[3][4][-1] # Legfelső elem

Lekövetkeztetett Elméleti Összegzés

  • Mátrix Transzformáció: A képernyőn megjelenő minden 2D alakzat végső soron egy diszkrét 2D vagy 3D tömbre képezhető le.
  • Rétegkezelés: A veszteségmentes vektorgrafikus rekonstrukcióhoz a mátrix elemeinek nem egyszerű számértékeknek, hanem **réteg-stackeknek** kell lenniük.
  • Indexszámítás: Az 1D-s tömbben történő sorfolytonos tárolás képlete: Index = Row × Cols + Col.
