2. Ritka Mátrixok (CSR) a Játékfejlesztésben

Mi az a Ritka Mátrix (Sparse Matrix)?
Amikor a 10x10-es Puzzle-ban, vagy a Meseerdő és Répás kert óriási pályáin játszol, a mezők többsége üres. Az olyan mátrixot, ahol a cellák túlnyomó része 0, ritka mátrixnak nevezzük.

2.1 Memóriapazarlás Hagyományos Tárolásnál

Egy $1000 \times 1000$-es játéktér 1 000 000 mezőt tartalmaz. Ha ezen csak 5 elem (pl. fa vagy répa) található, a többi 999 995 nulla feleslegesen terheli a számítógép memóriáját.

Sűrű Mátrix =
5000
0080
0306
0000

2.2 A CSR (Compressed Sparse Row) Megoldás

A CSR módszer mindössze 3 tömb segítségével tárolja el a teljes játékrácsot:

  • Data (értékek): [5, 8, 3, 6] – Kizárólag a nem-nulla elemek.
  • Indices (oszlopok): [0, 2, 1, 3] – Az elemek oszlopindexei.
  • Indptr (sor-mutatók): [0, 1, 2, 4, 4] – A sorok kezdőpozíciói.

2.3 Python CSR Implementáció

import numpy as np from scipy.sparse import csr_matrix # Sűrű játékrács létrehozása jatekracs = np.array([ [5, 0, 0, 0], [0, 0, 8, 0], [0, 3, 0, 6], [0, 0, 0, 0] ]) # Átalakítás memóriatakarékos CSR mátrixszá ritka_racs = csr_matrix(jatekracs) print("Eltárolt értékek (data):", ritka_racs.data)
