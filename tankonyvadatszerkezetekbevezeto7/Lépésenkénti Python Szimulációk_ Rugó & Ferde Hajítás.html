Idő (t): 0.00 s
Kitérés (x): 1.50 m
Sebesség (v): 0.00 m/s
Gyorsulás (a): -15.00 m/s²
# 1. Paraméterek és kezdőértékek
m, k, c = 1.0, 10.0, 0.35
x, v, t, dt = 1.5, 0.0, 0.0, 0.02
# 2. Ciklus lépésenként
while t < 10.0:
    a = (-k * x - c * v) / m
    v = v + a * dt
    x = x + v * dt
    t = t + dt

Fizikai Képletek (Oszcillátor)

Eredő gyorsulás: a = (-k * x - c * v) / m

Léptetés (Euler): v_új = v + a * dt  |  x_új = x + v * dt

Idő (t): 2.06 s
Távolság (x): 12.60 m
Magasság (y): 0.00 m
Sebesség (v): 7.82 m/s
# 1. Kezdőfeltételek (v0=28.28 m/s, ש=45°)
g, m, k, dt = 9.81, 1.0, 0.12, 0.02
x, y, vx, vy, t = 0.0, 0.0, 20.0, 20.0, 0.0
# 2. Szimulációs ciklus léptetése
while y >= 0:
    v = (vx**2 + vy**2)**0.5
    ax = -(k / m) * v * vx
    ay = -g - (k / m) * v * vy
    vx += ax * dt; vy += ay * dt
    x += vx * dt; y += vy * dt; t += dt

Fizikai Képletek (2D Ferde Hajítás)

X és Y irányú gyorsulás: ax = -(k/m)*v*vx  |  ay = -g - (k/m)*v*vy

Eredő sebesség nagysága: v = √(vx² + vy²)
