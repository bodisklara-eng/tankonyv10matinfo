1. JavaScript Interaktív Mátrix Skaláris Szorzás

Hogyan magyarázom ezt diákként?

A skaláris szorzás során azt teszem, hogy fogom a mátrix minden egyes elemét, és megszorozom ugyanazzal a megadott k számmal.

  • Műveleti szabály: Ha az eredeti mátrixom neve A, és a skalár k, akkor az új B mátrix elemeit így számolom ki: B[i][j] = k * A[i][j].
  • Dimenzió: Megőrzöm a méretet! Egy sorok_száma × oszlopok_száma méretű mátrixból pontosan ugyanolyan méretű eredményt hozok létre.

2. Python Mátrix Skaláris Szorzás

Itt megtekintheted a tiszta Python kód implementációt, és ki is próbálhatod a futtatását a saját megadott értékeiddel.

# Mátrix skaláris szorzás megvalósítása Python nyelven
def scalar_multiply(matrix, k):
    # Létrehozom az új mátrixot üres listaként
    result = []
    for row in matrix:
        new_row = []
        for val in row:
            # Megszorozom a mátrix minden elemét a skalárral
            new_row.append(val * k)
        result.append(new_row)
    return result

# Példa használat:
A = [[2, 4, -1], [0, -3, 5]]
k = 3
B = scalar_multiply(A, k)
print("Eredmény mátrix:", B)

3. C++ Mátrix Skaláris Szorzás

Itt tanulmányozhatod a C++ nyelvű megvalósítást std::vector konténerek segítségével, és tesztelheted is a futtatási logikát.

#include <iostream>
#include <vector>

// Függvény a mátrix skaláris szorzásához
std::vector<std::vector<int>> scalarMultiply(const std::vector<std::vector<int>>& A, int k) {
    int rows = A.size();
    int cols = A[0].size();
    std::vector<std::vector<int>> B(rows, std::vector<int>(cols));
    
    for (int i = 0; i < rows; ++i) {
        for (int j = 0; j < cols; ++j) {
            B[i][j] = A[i][j] * k; // Megszorozom az elemet
        }
    }
    return B;
}
