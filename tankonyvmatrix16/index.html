6.1 A Memória- és Ciklus-pazarlás Problémája

Ha egy 10 000 × 10 000-es mátrixot sima kétdefiníciós tömbként (Dense Matrix) tárolunk C++ vagy Java nyelven:

  • Memóriaigény: 100 000 000 elem × 8 byte (double) ≈ 800 MB RAM!
  • Ha a mátrix 99%-a 0, akkor 792 MB memóriát pazarolunk el a semmi tárolására, és a mátrixszorzás során a CPU-ciklusok 99%-a felesleges 0 · x = 0 számításokra megy el.

6.2 CSR (Compressed Sparse Row) Tárolás

A CSR adatstruktúra a nullákat eldobja, és 3 egydimenziós tömböt tart fenn:

1. V értékek tömb: [ 5, 8, 3, 6 ] (Csak a nem-nulla értékek) 2. COL_INDEX tömb: [ 0, 2, 1, 2 ] (Melyik oszlopban vannak) 3. ROW_PTR tömb: [ 0, 2, 3, 4 ] (Hol kezdődnek az egyes sorok)

6.3 Számítási Komplexitás Összehasonlítása

Típus Memóriakomplexitás Szorzási Időkomplexitás
Hagyományos (Dense) O(N²) O(N³)
Ritka (CSR Sparse) O(NNZ) * O(N + NNZ)

* NNZ = Number of Non-Zero elements (A nem-nulla elemek száma).

⚡ C++ Transzformációs Mátrix Klasszikus C++11
#include <iostream> #include <cmath> struct Vector2 { float x, y; }; // 2x2 Mátrix és Vektor szorzása (v' = M * v) Vector2 transform(float M[2][2], Vector2 v) { Vector2 res; res.x = M[0][0] * v.x + M[0][1] * v.y; res.y = M[1][0] * v.x + M[1][1] * v.y; return res; } int main() { Vector2 v = {3.0f, 4.0f}; // 90 fokos forgatási mátrix beállítása float rad = 90.0f * M_PI / 180.0f; float R[2][2] = { { cos(rad), -sin(rad) }, { sin(rad), cos(rad) } }; Vector2 v_rot = transform(R, v); std::cout << "Eredmeny: (" << v_rot.x << ", " << v_rot.y << ")\n"; return 0; }
