1 💡 Mi az a halmaz?

A Pythonban a set egy olyan adatszerkezet, amely egyedi elemeket tárol. Egy elem csak egyszer szerepelhet benne.

gyumolcsok = { "alma", "banán", "körte" }

szamok = { 1, 2, 2, 3, 3 }
# A Python eltávolítja a duplikációkat
# eredmény: {1, 2, 3}

💡 Tipp

A halmazok különösen hasznosak, amikor egyedi elemekkel szeretnél dolgozni.

Például ha egy listából szeretnéd eltávolítani az ismétlődéseket:

lista = [1,2,2,3,3]
halmaz = set(lista)
