1. Fejezet — AlapokOhm törvény

1. Alapok: LED, ellenállás, Ohm törvény

A LED (Light Emitting Diode) nyitóirányban kb. 2.0-3.2V-ot ejt. Az áramát előtét-ellenállással korlátozzuk, különben tönkremegy. Ohm törvény: U = I·R. Az előtét: R = (Utáp - Uled) / Iled.

R = (5V - 2.0V) / 0.015A = 200Ω → válassz 220Ω szabványt

Gyakorlatban 10-20 mA biztonságos egy 5 mm-es LED-nek. Nagyobb áramhoz már tranzisztor kell (2. fejezet). Polaritásra figyelj: hosszabb láb az anód (+).

🔍 MIT KELL MEGFIGYELNIE?
Mérd meg az ellenálláson eső feszültséget. Ha Utáp=5V és Uled=2.1V, akkor UR=2.9V. Ebből I=UR/R ellenőrizhető.
📌 MIT KELL MEGJEGYEZNIE?
LED sosem mehet előtét nélkül közvetlen 5V-ra! 330Ω univerzális védőérték kezdőknek. Piros LED Uf≈1.9V, kék/fehér ≈3.0V.

Kód: LED villogtatás

C++ Arduino
// Arduino C++ - LED Blink
const int LED_PIN = 13;

void setup() {
  pinMode(LED_PIN, OUTPUT);
}

void loop() {
  digitalWrite(LED_PIN, HIGH); // LED BE
  delay(500);
  digitalWrite(LED_PIN, LOW);  // LED KI
  delay(500);
}
MicroPython
# MicroPython - LED Blink
from machine import Pin
import time

led = Pin(2, Pin.OUT)  # beépített LED

while True:
    led.value(1)  # BE
    time.sleep(0.5)
    led.value(0)  # KI
    time.sleep(0.5)

2. Fejezet — Tranzisztoros kapcsolóMOSFET

2. Tranzisztoros kapcsoló és MOSFET

Egy mikrokontroller láb maximum 20-40 mA-t ad. LED szalag, motor, nagy fényerejű COB LED már 0.5-3A-t kér. Ilyenkor NPN tranzisztor (2N2222, BC337) vagy N-MOSFET (IRLZ44N, AOZ1284) kapcsol.

+12V ──[LED szalag]──┬── Drain (MOSFET)
                      │
                    Gate ──[100Ω]── D9 (PWM)
                      │
                  Source ── GND ── közös GND Arduinoval
Figyelem: Gate lehúzó 10kΩ GND-re!
🔍 MIT KELL MEGFIGYELNIE?
NPN esetén a bázisáram kb. a kollektoráram 1/10-e kell telítéshez. MOSFET-nél nincs DC bázisáram, de a Gate kapacitást tölteni kell - ezért kell 100Ω soros ellenállás.
📌 MIT KELL MEGJEGYEZNIE?
MOSFET választásnál logikai szintű (logic-level) típust keress: Vgs(th) < 2.5V. IRLZ44N jó 5V-ról és 3.3V-ról is. Mindig közösítsd a GND-t!

Kód: Tranzisztoros kapcsoló vezérlése

C++ Arduino
// Arduino C++ - NPN 2N2222 kapcsoló
const int TR_PIN = 9;
const int STRIP_PIN = 3; // MOSFET gate

void setup() {
  pinMode(TR_PIN, OUTPUT);
  pinMode(STRIP_PIN, OUTPUT);
}

void loop() {
  // Tranzisztor telítésbe vezérlése
  digitalWrite(TR_PIN, HIGH);
  delay(1000);
  digitalWrite(TR_PIN, LOW);
  delay(1000);
}
MicroPython
# MicroPython - MOSFET kapcsoló
from machine import Pin
import time

tr = Pin(5, Pin.OUT)

while True:
    tr.value(1) # Telítés: nagy áram folyik
    time.sleep(1)
    tr.value(0) # Zárás
    time.sleep(1)

3. Fejezet — 555 astabilf=1.44/((R1+2R2)C)

3. 555-ös IC astabil multivibrátor

Az NE555 a legklasszikusabb villogtató IC. Astabil módban nincs stabil állapota, folyamatosan billen. Belül két komparátor, egy RS flip-flop és egy kisütő tranzisztor van.

f = 1.44 / ((R1 + 2·R2)·C)   |   D = (R1+R2)/(R1+2·R2)   |   tHIGH = 0.693·(R1+R2)·C

Példa: R1=1k, R2=68k, C=10µF → f≈1Hz, D≈50%. A kimenet (3. láb) 200mA-ig terhelhető, LED közvetlen hajtható 470Ω-mal. A frekvencia hangolható potméterrel.

555 bekötés astabil:
1-GND, 8-VCC(5-12V), 4-RESET->VCC, 5-CONT->100nF->GND
2-TRIG + 6-THR közös -> R2 -> 7-DISCH -> R1 -> VCC
2-6 csomópont -> C -> GND, 3-OUT -> LED
C = 10µF, R1=1k, R2=47k potméter sorban
🔍 MIT KELL MEGFIGYELNIE?
Oszcilloszkópon (vagy Falstad szimulátorban) figyeld a kondenzátor fűrészfog feszültségét a 2-6 lábakon 1/3 VCC és 2/3 VCC között.
💡 GONDOLATOK
Miért nem lehet pontosan 50% kitöltés sima astabillal? Hogyan oldanád meg diódával, hogy tHIGH = tLOW legyen? (Tipp: dióda R2-t áthidalja)

Kód: 555 logika szoftverben

C++ Arduino
// Arduino - 555 astabil emuláció
// f = 1.44 / ((R1+2*R2)*C)
const int OUT = 13;
float R1 = 1000, R2 = 10000, C = 0.00001;
float tHigh = 0.693*(R1+R2)*C;
float tLow  = 0.693*R2*C;

void loop() {
  digitalWrite(OUT, HIGH);
  delay(tHigh*1000);
  digitalWrite(OUT, LOW);
  delay(tLow*1000);
}
MicroPython
# MicroPython - 555 astabil szimuláció
from machine import Pin
import time

R1, R2, C = 1000, 10000, 10e-6
tH = 0.693 * (R1+R2) * C
tL = 0.693 * R2 * C
led = Pin(2, Pin.OUT)

while True:
    led.value(1)
    time.sleep(tH)
    led.value(0)
    time.sleep(tL)

4. Fejezet — PWMDuty cycle

4. PWM fényerőszabályzás

A PWM (Pulse Width Modulation) gyors ki-be kapcsolással szimulál analóg feszültséget. A kitöltési tényező (duty) aránya adja a fényerőt: Uátlag = D·Utáp. 200 Hz felett szemünk nem lát villogást.

Duty = tBE / (tBE + tKI) ·100% | 25% = halvány, 50% = félfény, 100% = max

Arduino Uno 490 Hz / 976 Hz PWM-et ad (analogWrite). ESP32 akár 40 kHz-et. MOSFET-tel kombinálva 12V szalag is szabályozható. A csillogó effektek titka: szinuszos vagy random PWM minták.

🎓 MIT KELL TUDNIA?
Tudja kiszámolni a duty-t és tudja, hogy a PWM frekvenciának magasabbnak kell lennie, mint a szem fúziós frekvenciája (50 Hz), de hangfrekvencia alatt (20 kHz) zúghat a tekercs.
🔍 MIT KELL MEGFIGYELNIE?
Kapcsolj oszcilloszkópot a MOSFET Gate-re. 25% duty esetén a bekapcsolási idő negyede a periódusnak. Növeld a frekvenciát és figyeld a kapcsolási veszteséget.

Kód: Breath & Fade

C++ Arduino
// Arduino - PWM fade 0-255
const int LED = 9; // PWM képes láb

void setup() { pinMode(LED, OUTPUT); }

void loop() {
  for(int d=0; d<=255; d++){
    analogWrite(LED, d); // kitöltés
    delay(10);
  }
  for(int d=255; d>=0; d--){
    analogWrite(LED, d);
    delay(10);
  }
}
MicroPython
# MicroPython - PWM fade
from machine import Pin, PWM
import time

pwm = PWM(Pin(5), freq=1000)

for _ in range(2):
    for duty in range(0, 1024):
        pwm.duty(duty)
        time.sleep_ms(5)
    for duty in range(1023, -1, -1):
        pwm.duty(duty)
        time.sleep_ms(5)

5. Fejezet — HanghatásokPiezo & 555 monostabil

5. Hanghatások — piezo, buzzer, 555 monostabil

A piezo hangszóró kapacitív terhelés: közvetlen mikrokontroller lábról halk, de tranzisztorral hangos. Frekvencia = hangmagasság, kitöltés = hangerő. A 555 monostabil módban egy triggerre T=1.1·R·C ideig szól.

Alap dallam: A=440Hz, C=523Hz, E=659Hz. A tone() könyvtár 31 Hz - 65535 Hz között tud. Piezo csatolás: NPN kollektorában 100Ω + piezo + 12V, bázis 1kΩ mikrokontrollerről. Védődióda nem kell, mert piezo nem induktív.

📌 MIT KELL MEGJEGYEZNIE?
Piezo hangszóró polaritásfüggetlen, de a pozitív jelölés a hangosabb oldal. Buzzer aktív (beépített oszcillátor) csak tápot kér, piezo passzív - frekvenciát te adsz.
🔍 MIT KELL MEGFIGYELNIE?
Figyeld meg Falstad-ban: 555 monostabilban a kondenzátor exponenciálisan tölt 2/3 VCC-ig. A kimenet addig magas, amíg el nem éri a küszöböt.

Kód: Piezo dallam

C++ Arduino
// Arduino - Piezo tranzisztoros csatolás
const int BUZZER = 8; // NPN-en keresztül

void setup(){}

void loop(){
  tone(BUZZER, 440, 200); // A hang
  delay(250);
  tone(BUZZER, 523, 200); // C
  delay(250);
  tone(BUZZER, 659, 400); // E
  delay(600);
}
MicroPython
# MicroPython - Piezo dallam PWM-mel
from machine import Pin, PWM
import time

buzzer = PWM(Pin(12), freq=440)

def beep(freq, ms):
    buzzer.freq(freq)
    buzzer.duty(512)
    time.sleep_ms(ms)
    buzzer.duty(0)
    time.sleep_ms(50)

beep(440, 200)
beep(523, 200)
beep(659, 400)

6. Fejezet — Mikrokontrolleres csillogásÖsszefoglalás

6. Mikrokontrolleres csillogás — haladó effekt

Most jön a lényeg: kombináld a tranzisztort, PWM-et és véletlent! A profi csillogás nem egyforma villogás, hanem twinkle, glitter, breath és VU keveréke. NeoPixel WS2812B esetén egy vezetéken 100 LED is vezérelhető.

Haladó minta: minden LED-nek saját fázisa van (sin(phase+time)). Random csillanás: 1% eséllyel egy LED 100%-ra ugrik 50 ms-ra, majd vissza. Ezzel élethű csillagos ég effektet kapsz.

💡 GONDOLATOK
Hogyan kerülnéd el, hogy 100 LED egyszerre kapcsoljon és megrántsa a tápot? (Tipp: lágy indítás, staggered update, nagy elkó a tápon, 470µF)
🎓 MIT KELL TUDNIA? — Követelmény
  • Ohm törvény alkalmazása LED-re
  • Tranzisztor mint kapcsoló méretezése (IB = IC / β)
  • 555 astabil frekvencia számítás
  • PWM duty és átlagfeszültség összefüggése
  • Piezo csatolás tranzisztorral és hangfrekvencia generálás

Kód: Kapacitív csillogó ruha

C++ Arduino
// Arduino - Érintésre csillogás
#include <CapacitiveSensor.h>
CapacitiveSensor cs = CapacitiveSensor(4,2);
const int LEDS[] = {3,5,6,9,10,11};

void loop(){
  long touch = cs.capacitiveSensor(30);
  if(touch > 800){
    // Glitter effekt
    for(int i=0;i<20;i++){
      int r = random(6);
      analogWrite(LEDS[r], random(255));
      delay(60);
      analogWrite(LEDS[r], 0);
    }
  }
}
MicroPython
# MicroPython - TouchPad csillogás
from machine import TouchPad, Pin, PWM
import time, random

touch = TouchPad(Pin(4))
leds = [PWM(Pin(p)) for p in [5,18,19]]

while True:
    if touch.read() < 300: # érintés
        for _ in range(20):
            l = random.choice(leds)
            l.duty(random.randint(0,1023))
            time.sleep_ms(60)
            l.duty(0)
    time.sleep_ms(50)
🔍 MIT KELL MEGFIGYELNIE?
Figyeld a tápfeszültséget oszcilloszkópon glitter közben. Ha 500 mV-nál nagyobb a tüskésedés, tegyél 100nF kerámia kondit minden IC tápjára és 470µF elkót a fő tápra.
📌 MIT KELL MEGJEGYEZNIE?
WS2812B táp: 5V 60mA/LED max → 30 LED = 1.8A! Mindig külön táp, közös GND, 330Ω adatvonalra. Ne felejtsd a 1000µF kondit a LED szalag elején.
