C++ Főátló Mátrix Genereálás Szimulátor

Főátló: 0 (i==j) | Főátló felett: 1 (i<j) | Főátló alatt: 2 (i>j)

Forráskód

int a[100][100], i, j, n;
cin >> n; // n = 3
for(i = 1; i <= n; i++)
    for(j = 1; j <= n; j++) {
        if(i == j) a[i][j] = 0;
        else if(i < j) a[i][j] = 1;
        else a[i][j] = 2;
    }
for(i = 1; i <= n; i++) { ... afişare ... }
