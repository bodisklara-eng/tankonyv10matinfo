Párhuzamos C++ `std::vector>` és Python `List[List[T]]` bejárás

#include <iostream>
#include <vector>
#include <string>

struct Student { std::string nev; int nap; };

int main() {
    // 12 hónapnak megfelelő külső vektor létrehozása
    std::vector<std::vector<Student>> szulinaptar(12);

    // Kétdimenziós vektor bejárása [i][j] indexekkel
    for (size_t i = 0; i < szulinaptar.size(); ++i) {
            for (size_t j = 0; j < szulinaptar[i].size(); ++j) {
                    std::cout << "[" << i << "][" << j << "]: " 
                      << szulinaptar[i][j].nev << std::endl;
        }
    }
    return 0;
}
from typing import List

# 12 hónapnak megfelelő beágyazott lista létrehozása
szulinaptar: List[List[dict]] = [[] for _ in range(12)]

# Bejárás kétszeres for ciklussal
for i, honap in enumerate(szulinaptar):
    for j, diak in enumerate(honap):
        print(f"[{i}][{j}]: {diak['nev']} ({diak['nap']}. nap)")

Naptár & Vektor Súgó

Mi az a 2D Vektor?

Ez az alkalmazás a programozásban használt kétdimenziós tömböt (vektort a vektorban) szemlélteti:

  • Fő vektor [i]: A 12 hónap oszlopa (0=Január, 11=December).
  • Beágyazott vektor [j]: Az adott hónap alatt lógó diák korongok sorrendje.

Funkciók Útmutatója:

  • 1. Új diák: Kattints a "+ Új diák" gombra, töltsd ki a nevet és születési napot!
  • 2. Áthúzás (Drag & Drop): Fogd meg bármelyik lógó korongot és húzd át egy másik hónap oszlopába!
  • 3. Vektor Bejárás: A "Vektor bejárás" gomb animáltan végiglépked az összes [i][j] elemen, miközben a kódszimulátorban is kiemeli az épp futó sort.
  • 4. Szerkesztés / Törlés: Vidd az egeret a korongra a szerkesztő és törlő gombok megjelenítéséhez.
